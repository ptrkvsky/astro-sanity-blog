Entrée d'un bouton flottant : avant et après

Même bouton, même page. Seule la façon d'arriver change : un mouvement qui s'arrête net contre un mouvement qui a de l'inertie, suivi d'un signal qui retient le regard.

L'essentiel du code

/* Courbe à ressort : dépasse la cible d'environ 12 % puis revient */
--spring: cubic-bezier(0.34, 1.56, 0.64, 1);

.dock { transition: transform 300ms var(--spring); }

/* La cloche attend 0,4 s après l'arrêt du bouton, puis sonne une seule fois */
.is-ringing .bell { animation: ring 1.8s ease-in-out 0.4s 1; transform-origin: top center; }

// Déclenché après le montage : le HTML serveur reste identique
setTimeout(() => el.classList.add('is-entered'), 1500);
dock.addEventListener('transitionend', (e) => {
  if (e.target === dock) el.classList.add('is-ringing');
});
